# 밥투게더 (boptogether)

캘린더에서 날짜를 골라 주문을 등록하고, 함께 먹을 사람들이 이름과 메뉴를 남긴 뒤,
주문자가 참여자별 정산금액과 입금 계좌를 관리할 수 있는 간단한 웹앱입니다.
최대 10명까지 한 주문에 참여할 수 있습니다.

## 기능

- 캘린더에서 날짜 선택 후 주문 등록 (주문자이름 / 매장명 / 주문날짜 / 주문시간)
- 주문 상세 페이지에서 누구나 이름 / 메뉴를 입력해 참여 (최대 10명)
- 참여자별 정산금액 입력, 정산 계좌(은행명 / 예금주 / 계좌번호) 등록
- 참여자 삭제, 실시간 합계 표시

## 웹사이트로 배포하기 (친구들과 링크 공유용)

설치 없이 다 같이 쓸 수 있는 링크가 필요하다면, 무료 호스팅 서비스인
[Render](https://render.com)에 3단계만 거치면 배포됩니다. (카드 등록 불필요)

1. [render.com](https://dashboard.render.com/select-repo?type=blueprint) 접속 후 GitHub 계정으로 로그인
2. `sujeong-yooon/boptogether` 저장소 선택 → **Apply**
   (저장소에 있는 `render.yaml`을 Render가 자동으로 읽어서 빌드/실행 명령을 알아서 설정해요)
3. 배포가 끝나면 `https://boptogether-xxxx.onrender.com` 같은 링크가 생성됩니다.
   이 링크를 친구들에게 공유하면, 설치 없이 바로 캘린더 웹앱을 쓸 수 있어요.

무료 플랜은 일정 시간 접속이 없으면 서버가 잠들었다가, 링크를 다시 열 때
첫 로딩이 몇십 초 정도 걸릴 수 있어요(정상입니다, 기다리면 켜져요). 저장된
주문/정산 데이터는 재배포(코드 업데이트 반영)를 하기 전까지는 계속 유지됩니다.

## 로컬에서 실행하기 (개발용)

```bash
npm install
npm start
```

`http://localhost:3000` 에서 접속할 수 있습니다.

데이터는 `data/boptogether.db` (SQLite) 파일에 저장됩니다.
